# 使用指南

[项目首页](../README.md) · [Windows 便携使用](PORTABLE.md) · [构建说明](BUILD.md)

## 选择工具与导入

首页提供压缩图片、调整尺寸和转换格式三个独立入口，可搜索工具名称。选择工具后导入文件或文件夹，也可直接拖放；文件夹默认包含子目录，可取消递归。首页接收的拖放路径会暂存，选择工具后才导入。

各工具分别保留文件列表、选择、参数和处理结果，切换工具不会把压缩参数带到尺寸或转换页面。语言、输出位置和递归导入选项共用。只有当前工具加载预览，避免同时保留多套图片像素。

选择与输入分开的输出目录，再开始批量处理。原文件不覆盖，输出保留相对目录结构；遇到同名文件自动添加编号。结果展示每个文件的状态、输入/输出大小与尺寸，部分失败不会使已完成结果丢失。

## 压缩图片

压缩保持输入格式、像素尺寸和 GIF 动画。JPEG / 静态 WebP 可调整质量，默认值分别为 85 / 80；质量越低通常体积越小，也可能出现细节损失。可拖动滑杆或直接编辑数值。

无损选项使用对应格式的优化方式：JPEG 保留压缩系数，PNG 使用无损优化，WebP 支持无损编码，GIF 保留播放内容。已优化文件可能几乎不变甚至变大；以结果的实际字节数为准。

“无损”描述编码或优化步骤。颜色空间转换、降低位深、缩放或格式转换造成的信息变化，应另行判断。

## 调整尺寸

尺寸工具改变像素宽高，支持：

| 模式 | 含义 | 示例 |
| --- | --- | --- |
| 宽高边界 | 保持比例缩到指定矩形内，不强制拉伸到矩形尺寸 | 4000×3000 放入 1920×1080，得到 1440×1080 |
| 最长边 | 限制较长的一边，另一边按比例计算 | 4000×3000 → 最长边 1920 → 1920×1440 |
| 百分比 | 相对本次实际输入缩放 | 4000×3000 → 50% → 2000×1500 |

默认不放大，只有明确允许放大后才处理比输入更大的目标。格式与 GIF 动画保留；高级编码选项用于控制缩放后的重新编码，JPEG / WebP 默认质量为 95 / 90。此工具不提供“压到 500 KB 以下”等精确文件体积限制。

## 转换格式

选择 JPEG、PNG、静态 WebP 或 GIF 为目标格式，页面只显示该格式相关的编码选项。转换保持输入像素尺寸。JPEG 不支持透明；需要移除透明度时使用所选底色合成。

静态图片转 GIF 最多 256 色，仅支持全透明或不透明；半透明像素按底色合成。PNG 16 位转到不支持该精度的格式时会降低精度。

动画 GIF 转静态格式必须明确选择导出首帧，不会静默丢弃后续动画。GIF 压缩和缩放保留帧内容、时长与循环。

## 重新调整与继续调整

这两个操作采用不同的输入来源：

| 操作 | 输入 | 参数与启动方式 |
| --- | --- | --- |
| 重新调整 | 最初导入的原图 | 恢复当前工具上次处理的参数供修改；重新确认开始 |
| 继续调整… | 选中的成功输出 | 选择下一工具，使用目标工具自己的参数；重新确认开始 |

例如原图 4000×3000 先缩到 2000×1500，再“继续调整”按 50% 缩放，得到 1000×750；如果从原图“重新调整”按 50% 缩放，则得到 2000×1500。重新调整不会自动重演之前的处理链。

继续调整会把成功输出追加到目标工具已有队列，保留已有条目与结果；原有条目取消选择，仅新传入的条目被选中。失败或取消项不传入。成功输出仍保留最初原图的来源关系。

准备时会检查实际输入是否可用。最初原图丢失或发生变化时，重新调整需要重新导入；继续调整只要求本次采用的成功输出仍可读取。

## 导航与取消

点击“← 所有工具”返回首页，也可通过当前工具菜单直接切换。准备检查期间允许导航；也可点击“取消检查”或按 Esc。

取消尚未完成的继续调整准备，只撤回本次新增条目，并恢复目标工具此前的选择、焦点和计数。已经检查完成的传入项会保留，之后可以返回处理。取消重新调整准备会撤销自动恢复的参数；若在检查期间手动修改过参数，则保留手动修改。

实际批处理、导入和原生文件对话框期间暂不能切换工具。取消批处理后停止安排新任务，已开始的任务在安全阶段退出；已完成输出保留，未完成结果不提交。受理取消后后台退出可能仍需一点时间。

## 设置、元数据与会话

各工具分别保存处理参数和元数据偏好。默认删除拍摄等非显示必需元数据；可选择保留目标格式能正确承载的支持字段。方向与颜色处理独立于元数据保留开关。

语言与参数在下次启动时恢复，文件队列、选择、结果列表和编辑历史仅保留在当前会话中。已输出图片保存在磁盘，不受退出影响。

便携模式在程序旁使用 `Data/settings.json`，普通模式使用用户配置目录。便携文件夹、输出路径与版本升级的具体行为见 [Windows 便携说明](PORTABLE.md)。

## 支持范围与资源

支持 JPG/JPEG、PNG、静态 WebP、静态及动画 GIF。不支持 HDR、APNG、动画 WebP、多页图和未识别格式；不提供 AI 模型去背景。单项不支持或超过资源预算时会报告原因，其他可处理项继续执行。

批处理优先控制内存，默认最多 4 个处理 worker，共享 1536 MiB 图像处理预留预算。大图会减少可同时运行的任务；该预算是调度估算，并非操作系统内存硬限制。设计负载、实际测量及限制见 [验证记录](VALIDATION.md) 和 [架构说明](ARCHITECTURE.md)。

## 命令行

`lit` 提供同一核心的命令行入口，适合重复执行或脚本调用：

```powershell
./lit.exe inspect "D:/Photos/example.jpg"
./lit.exe process "D:/Photos" --recursive --output "D:/Photos-export" --long-edge 1920
./lit.exe process "D:/Photos/example.png" --output "D:/WebP-export" --format webp --webp-quality 80 --report "D:/WebP-report.json"
./lit.exe process --help
```

macOS / Linux 将 `./lit.exe` 换为 `./lit`。可用 `--keep-metadata` 保留支持的元数据、`--lossless` 选择无损编码、`--gif-first-frame` 明确导出动画首帧；实际支持与组合约束以 `--help` 为准。CLI 允许组合缩放与转换参数，其相对路径按当前工作目录解析。

JSON 报告与已有输出均不覆盖。批次部分失败时保留成功结果，并以非零退出码结束；自动化脚本应同时检查退出码和报告中的逐项状态。
